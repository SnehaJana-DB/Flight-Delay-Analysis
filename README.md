# ✈️ Flight Delay Analysis Dashboard

## 📌 Project Overview

This project analyzes U.S. flight delay data using SQL and Power BI to identify patterns in airline performance, airport traffic, and delay causes.

The dashboard provides insights into flight operations and helps understand factors contributing to delays.

---

## 🎯 Objectives

- Analyze flight delay trends
- Identify busiest airlines and airports
- Evaluate airline performance
- Understand major causes of delays
- Create an interactive Power BI dashboard

---

## 🛠️ Tools Used

- MySQL Workbench
- SQL
- Power BI
- Excel

---

## 📊 Dataset

Source: Kaggle - U.S. Flight Delay Data (2015)

Tables used:

- Flights
- Airlines
- Airports

Dataset contains approximately 78,000 flight records.

---

## 🔍 Key Business Questions

1. Which airline operated the highest number of flights?
2. Which airline experienced the highest average delay?
3. Which airports handled the most flights?
4. What were the primary causes of delays?
5. Which day of the week experienced the highest delays?
